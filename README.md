# Showdown
A simple peer-to-peer shooter battle royale game.

### How to Run

1. **Start the Peer Application**  
   - **On Windows:** Double-click the JAR file.  
   - **On any system using a terminal:** Run the following command:
     ```bash
     java -jar showdown-x.y.z.jar
     ```

2. **Start the Lobby Server**  
   Open a terminal and execute the following command:
   ```bash
   java -jar showdown-server-x.y.z.jar
   ```
